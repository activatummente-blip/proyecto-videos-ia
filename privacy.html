Política de privacidad

Proyecto Videos IA Desktop es una aplicación personal de escritorio para crear, preparar y publicar contenido audiovisual propio en TikTok.

Acceso a TikTok

La aplicación utiliza la autenticación OAuth de TikTok. Según las funciones habilitadas, puede solicitar permisos como user.info.basic, video.publish y video.upload. TikTok muestra los permisos solicitados durante la autorización.

Almacenamiento y uso de datos

Las credenciales de la aplicación y los tokens OAuth se almacenan localmente en el equipo del usuario. Se usan para identificar la cuenta autorizada y realizar las operaciones que el usuario elija. Los videos y sus datos de publicación se envían a TikTok solo cuando el usuario autoriza la acción.

No vendemos datos personales. No compartimos datos con terceros, salvo la información necesaria para interactuar con las APIs oficiales de TikTok y prestar la función de publicación solicitada.

Control del usuario

El usuario puede revocar los permisos de la aplicación desde la configuración de su cuenta de TikTok. También puede eliminar del equipo los archivos locales de credenciales y tokens para dejar de usar la integración.
